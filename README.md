# ⚛️ React Projects Collection

This repository contains multiple **React.js practice projects** created to understand core concepts, component-based architecture, state management, props, hooks, and real-world mini applications.

Each project has its **own folder** and a **separate README** explaining implementation details.

---

## 📂 Projects List

### 1️⃣ 03TailwaindCssProps

**Description:**
Learning and practicing **Tailwind CSS** with React props.

**Concepts Covered:**

* Tailwind CSS utility classes
* Passing and using props
* Component reusability

---

### 2️⃣ BackGroundChanger

**Description:**
A simple **background color changer application** built with React.

**Concepts Covered:**

* useState hook
* Event handling
* Dynamic styling

---

### 3️⃣ CurrencyChanger

**Description:**
A currency conversion project to understand data handling and UI updates.

**Concepts Covered:**

* State management
* Controlled inputs
* Logic-based UI rendering

---

### 4️⃣ PasswordGenerator

**Description:**
A password generator application with customizable options.

**Concepts Covered:**

* useState & useEffect
* Random value generation
* Form handling

---

### 5️⃣ viteBasic01

**Description:**
A basic counter application created using **Vite + React**.

**Concepts Covered:**

* Vite setup
* useState hook
* Component structure

---

### 6️⃣ TodoList (MERN)

**Description:**
A **Todo List Application** built using the **MERN Stack** with MongoDB for persistent storage.

**Concepts Covered:**

* React frontend
* Node.js & Express backend
* MongoDB with Mongoose
* REST API integration
